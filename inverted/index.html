Why does MLS stay so competitive?

MLS is built for parity: a salary cap, limited star slots, no relegation. This project measures how much that shows up on the pitch, where it comes from, and what it means for a club deciding where to spend.

Each question below leads to the next. Every level has its own page, and the simulator is one click away from all of them.

How it was built

Every number on this site comes from a script in the public repository. Each stage of the work has a check that could have failed, and the results are published either way.

  1. Public data only. Match data from American Soccer Analysis, closing odds from football-data.co.uk, lineups from ESPN, and salaries only from the MLS Players Association releases. When the simulator was rebuilt on public data, it reproduced the original: the spread of team quality matched to 13 decimal places, and player ratings correlated at 0.999995 (validation report).
  2. The test is written first. Paper 2's predictions were written before the analysis data was downloaded and recorded in the project log (predictions, results). For the playoff forecast, seven style matchups and a rule for using them were set before any model was fitted. They improved predictions in 2 of 8 seasons against the 7 required, so they were left out.
  3. Measured against the market. Closing betting odds are the hardest benchmark in football forecasting, so every model is scored against them: 5,987 MLS matches for the team ratings, preseason futures for the simulator (0.81 correlation in 2025), and the 2023–2025 playoffs for the playoff forecast (log loss 0.962 against 0.954 for the closing odds). Where the market wins, as it does against Paper 1's model by 0.035, the page says so.
  4. Failed checks stay in. Paper 1 ran 16 validation checks: 8 passed, 7 failed and 1 partly passed. Paper 2's weak-link mechanism was not supported. In the playoff backtest a different setting scored slightly better after the fact, and the one chosen in advance was kept.
  5. Code checked against itself. AI tools help write and review the code, so each output gets an independent check before it ships. The playoff page's simulation engine was run on 400,000 brackets and matched the exact probabilities to within 0.2 percentage points, and the playoff seeds were rebuilt from the points table before use.
